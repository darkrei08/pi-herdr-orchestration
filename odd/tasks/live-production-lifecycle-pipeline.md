# Live software production lifecycle pipeline

This feature defines a staged software lifecycle from local change through beta, live runtime verification, and production delivery.
Read this document through `## Log` before acting.

## Specs

- **S1**: "Devi aggiungere poi nelle direttive di Peer Orchestrations in General Excellence che ogni qualvolta si applicano delle modifiche, dei commit o delle future consistenti, una volta che si applica la modifica bisogna fare l'audit, bisogna fare il test, il loop, bisogna provare concretamente i live in un'altra sessione page temporanea, l'esecuzione della correzione prima di andare poi in produzione."
- **S2**: "Quindi devi usare e scandire i diversi aspetti di cicli di sviluppo del software, in modo tale che una volta applicato il commit, se la modifica ha portato concretamente alla correzione o alla miglioria o l'implementazione, poi in runtime debba essere applicata la miglioria, non che si corregge il software e poi bisogna rifare il reload della sessione."
- **S3**: "cioè devi studiare esattamente come Peer Orchestration nella Skill Excellence Engineering si possa implementare affettuando anche una ricerca online col mio data steck che deve essere sempre usato come pipeline del ciclo di sviluppo del software, le best practice sia per GitHub che per il commit locale e per l'implementazione live, quindi analizzi online le best practice per il ciclo di sviluppo e di produzione di un software dalla fase stage beta fino all'aspetto produzione e test runtime live."
- **S4**: "Questo che ti ho appena indicato è un ulteriore task da implementare nella lista con appunto lo sviluppo con i sottoagenti utilizzando PX Rolls. Se proprio insisti, devi creare una skills di produzione del software oppure trovare online o su GitHub se esiste già una soluzione di questo tipo che si incentri esattamente sul ciclo di produzione del software questo ulteriore task non è altro che un altro work tree all'interno di Pair Dor Orchestrations, e quindi un altro branch di implementazione. Utilizzando la filosofia di Mat Pacco. In futuro poi utilizzeremo la filosofia di MatPacco dove implementarla, in quale ordine e così via, e anche per tante altre skill che sono presenti."
