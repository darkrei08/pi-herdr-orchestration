# Bootstrap and capability discovery

Inspect the actual machine before planning. Check Pi packages/extensions, skills, roles, GitHub access, package manager, runtime, build and tests. Also detect Wizard-AI (`WIZARD_AI_DIR`, `~/.wizard-ai/.wizard-ai.json`, `wz-ai`, `wizard-ai`, `@darkrei08/wizard-ai-cli`) and its installed context tools. Read installed instructions and `AGENTS.md`; names in old prompts are not proof of availability. Map capability → installed implementation → supported operations → constraints. From a checkout, run `node skills/repository-orchestrator/scripts/check-environment.mjs --json`; the report is read-only and is the source for installed/missing/incompatible status.

Treat the compatibility stack as a dependency registry, not a citation list. Check Pi, PiWorkflow, Pi VCC, Wizard-AI, TOON/LEA, RTK/sqz, Serena, graphify, Guardian Angel, Gentle/Engram and Herdr. For each one record `status`, `version`, `source`, `verified_by`, `required_for` and `config_ref`; see [dependencies.md](dependencies.md). A missing optional tool selects a documented fallback. If the user requests setup, show the package, version, command, scope and side effects, then execute only after explicit authorization. Before installing Wizard-AI or its managed tools, compare its memory, workflow, proxy and provider-routing components with the existing Gentle/Pi stack and skip overlapping components. For skill distribution, verify the target roots for Codex (`~/.codex/skills`), Claude Code (`~/.claude/skills`), Antigravity (`~/.gemini/config/skills`) and Antigravity CLI (`~/.gemini/antigravity-cli/skills`) after using the official `skills` CLI.

For Pi compaction, inspect the native Pi settings and the configured extension packages/hooks. Detect `pi-codex-context`, `@sting8k/pi-vcc`, legacy `@adamjen/pi-vcc`, or another installed compactor from the active settings and package metadata. Select exactly one owner for each path: the configured compactor when one is active, otherwise Pi core. Multiple active compactors are `incompatible`, not a reason to guess. Do not run Wizard-AI `sqz`, TOON or a custom summary over the active Pi transcript; use those tools only to prepare bounded evidence or handoff artifacts.

Prefer PiWorkflow for orchestration when present. Its current documentation governs workflow, worktree, role and subagent APIs. If absent, use ordinary Git and host-permitted orchestration and report the limitation. Discover the complete Gentle AI suite relevant to the host, including `gentle-pi`, Engram or another persistent memory adapter, Gentle personas, review guards, SDD/TDD workflows, skills, MCP integrations and project-scoped configuration; names and availability may vary. Gentle is the continuity and knowledge layer, while PiWorkflow remains the control plane. Discover Engineering Excellence, Matt Pocock, Gentle and local skills, reading only relevant instructions. Do not install dependencies silently or print secrets.
