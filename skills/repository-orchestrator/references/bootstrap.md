# Bootstrap and capability discovery

Inspect the actual machine before planning. Check Pi packages/extensions, skills, roles, GitHub access, package manager, runtime, build and tests. Also detect Wizard-AI (`WIZARD_AI_DIR`, `wz-ai`, `wizard-ai`, `@darkrei08/wizard-ai-cli`) and its installed context tools. Read installed instructions and `AGENTS.md`; names in old prompts are not proof of availability. Map capability → installed implementation → supported operations → constraints.

Prefer PiWorkflow for orchestration when present. Its current documentation governs workflow, worktree, role and subagent APIs. If absent, use ordinary Git and host-permitted orchestration and report the limitation. Discover the complete Gentle AI suite relevant to the host, including `gentle-pi`, Engram or another persistent memory adapter, Gentle personas, review guards, SDD/TDD workflows, skills, MCP integrations and project-scoped configuration; names and availability may vary. Gentle is the continuity and knowledge layer, while PiWorkflow remains the control plane. Discover Engineering Excellence, Matt Pocock, Gentle and local skills, reading only relevant instructions. Do not install dependencies silently or print secrets.
