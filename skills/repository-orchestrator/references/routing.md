# Dynamic skill routing

Read installed skill instructions and select the smallest sufficient set. PiWorkflow sequences tasks; Gentle/Engram provides continuity; Engineering Excellence, Matt Pocock and local skills may provide methods; Wizard-AI may provide discovery, compression, AST and graph tools. Resolve overlapping guidance using host, user and repository instructions.

| Situation | Candidate method if available |
| --- | --- |
| Reproducible bug | Root cause, regression test, minimal fix, review |
| Defined small feature | Implement, focused checks, review |
| Complex feature | Spec, dependencies, isolated implementation |
| Uncertain product problem | Wayfinder or research before specification |
| Ambiguous decision | Grilling or targeted user decision |
| Technical uncertainty | Time-boxed prototype, accept/reject |
| Long session | Handoff, durable memory, state reconciliation |
| Large codebase context | Serena/graphify for targeted evidence, then RTK/sqz/LEA/TOON as discovered |

These are examples, not guaranteed skill names or a mandatory pipeline.
